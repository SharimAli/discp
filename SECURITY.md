# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Discp, please **do not** open a public issue. Instead, please report security concerns responsibly by contacting the maintainer or opening a private security advisory on GitHub.

### Security Best Practices

* **Never commit `.env` or Discord tokens** to any public repository.
* Always use dedicated alt accounts or bot tokens with least-privilege permissions when testing integrations.
